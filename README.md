Blood Bank Management System

Project Overview

   The Blood Bank Management System is a web based application developed using Python and Django. It helps manage patients,donors,blood stock,and blood request.

Features

  * Patient Management
  * Donor Management
  * Blood Stock Management
  * Blood Request Management
  * Blood Availability Search
  * User Login
  * Hospital Blood Request
  * Patient ID Based Request
  * Request Status Management

Technologies Used

  * Python
  * Django
  * HTML
  * CSS
  * SQLite
  * Django Templates

How To Run

   1. Create and activate a virtual environment
   2. Install Django
   3. Run database migrations:
        * python manage.py makemigrations
        * python manage.py migrate 
   4. Start the development server:
        * python manage.py runserver
   5. Open the application at:
          http://127.0.0.1:8000/
